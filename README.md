# web

Веб-интерфейс платформы студенческих скидок: React 19, TypeScript, Vite, shadcn/ui и Tailwind CSS. API доступны через шлюз Kong.

## Запуск

Нужен Node.js 24.

```bash
npm ci
npm run dev        # http://localhost:5173
```

Для локальной интеграции запустите сервисы и пробросьте порт Kong по инструкции в соседнем репозитории [`infrastructure`](../infrastructure/README.md). Для входа достаточно запущенного Auth.

Адрес шлюза по умолчанию `http://localhost:8000`, другой задаётся в `.env` переменной `VITE_API_BASE_URL` (см. `.env.example`). Порт 5173 разрешён в CORS шлюза, поэтому менять его не нужно.

Проверка HTTP-клиента и обновления черновиков: `npm test`. Проверка типов и сборка: `npm run build`. Для nginx, проксирующего API с того же origin, соберите `VITE_API_BASE_URL='' npm run build`. Тесты и сборка запускаются в CI.

## Что есть

| Экран | Кому | Что можно сделать |
|---|---|---|
| Главная и поиск | всем | Фильтры, список, карта текущей страницы и карточки опубликованных мест |
| Регистрация, вход | всем | Ошибки сервера показываются с кодом и идентификатором запроса |
| Профиль | вошедшим | Роли, список сессий, завершение одной или всех сессий, выход |
| Пользователи | старшему модератору | Поиск по email, назначение и снятие модератора, блокировка с причиной и разблокировка, завершение сессий, история изменений |
| Мои заявки | вошедшим | Черновики, история и неизменяемые версии; студенты предлагают новые места, студенты и авторизованные представители предлагают скидки и исправления |
| Модерация | модераторам | Очередь, просмотр версии и доказательств, взятие в работу, решения, исправленные версии |
| Жалобы | студентам и модераторам | Подача по ID заявки и история своих жалоб; очередь рассмотрения, решение старшего модератора |

Пункты меню зависят от ролей из профиля, но это только удобство: права проверяет сервер, и при их нехватке интерфейс покажет ответ `403`.

## Как устроено

- `src/api/http.ts` — клиент API. Access-токен хранится в памяти, refresh-токен в `localStorage`, поэтому вход переживает перезагрузку страницы. При `401` клиент один раз обновляет токены и повторяет запрос. Параллельные обновления объединяются в одно, иначе auth примет повторное предъявление refresh-токена за кражу и завершит сессию.
- `src/api/auth.ts` — запросы к auth, `src/api/messages.ts` — тексты ошибок и названия ролей.
- `src/auth/AuthContext.tsx` — текущий пользователь, вход и выход.
- `src/pages/` — экраны, маршруты в `src/App.tsx`.

## Карта

MapLibre GL JS загружается только в режиме карты. По умолчанию используются растровые тайлы OpenStreetMap с атрибуцией; ключ не нужен. Для другого поставщика задайте обе переменные `VITE_MAP_TILE_URL` (шаблон XYZ) и `VITE_MAP_TILE_ATTRIBUTION`. Для развёртывания под нагрузкой выберите поставщика с подходящими условиями, учитывая [политику использования тайлов OpenStreetMap](https://operations.osmfoundation.org/policies/tiles/).

Координаты запрашиваются из каталога только для мест на текущей странице. Поиска по видимой области или радиусу нет. Без WebGL 2 или доступных тайлов список и карточки продолжают работать.

## Ограничения

- Публичная карточка не содержит ID заявки и приватных вложений. Жалобу можно подать по известному ID заявки или из своей опубликованной заявки.
- Выдача прав представителю организации и перечень категорий не предоставляются публичными API; при предложении места указывается код категории.
- Refresh-токен в `localStorage` доступен скриптам страницы. Для демонстрации это допустимо, в продакшене его лучше хранить в `HttpOnly` cookie: это изменение в auth.
- Если открыть приложение в двух вкладках, они могут одновременно обновить токен, и auth завершит сессию. Тогда нужно войти заново.
